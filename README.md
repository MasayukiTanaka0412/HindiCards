# Hindi Cards

ヒンディー語フレーズを練習するための静的Webアプリです。  
`phrases.md` の内容を使って、日常会話・オフィス会話のカード学習ができます。

## 主な機能

- 出題数を指定してクイズ開始（デフォルト: 20問）
- 日常会話セクションから半分、オフィス会話セクションから残りをランダム出題
- カード表示（ディーバナーガリー + ローマ字）
- 「答えを見る」で日本語訳を表示
- Web Speech API でディーバナーガリーを読み上げ（`hi-IN`）
- 「例文集を見る」で `phrases.md` を見やすい表形式で新規ウィンドウ表示

## ファイル構成

- `index.html` - アプリUI
- `styles.css` - スタイル
- `app.js` - クイズロジック・読み上げ・例文表示
- `phrases.md` - フレーズデータ

## 使い方

静的ファイルとして提供されているため、ローカルHTTPサーバーで起動してください。

```bash
python -m http.server 8000
```

その後、ブラウザで以下を開きます。

- `http://localhost:8000/index.html`

## 注意事項

- 読み上げ機能はブラウザの Web Speech API 対応状況に依存します。
- `phrases.md` はUTF-8で保存してください。
